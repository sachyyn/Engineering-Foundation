# Toolchain and activation

Root Node24/pnpm10 tooling is executable now. Run `pnpm install --frozen-lockfile --ignore-scripts`, `pnpm setup:tools`, `pnpm check`. setup:tools downloads actionlint1.7.12 from the official release, verifies a reviewed SHA256 for macOS/Linux x64/arm64, and extracts only binary/license into ignored `.tools`. It never installs globally. `pnpm check:foundation` runs route/config/workflow/path tests, Prettier, Secretlint and actionlint; root audit/license inventory are in `pnpm check`. Install scripts stay disabled. actionlint shellcheck/pyflakes integrations are disabled because these separate executables are not selected dependencies; workflow syntax/expression validation remains active.

The root `tooling/product.mjs` automatically detects `backend/composer.json`, `frontend/package.json`, or each application's src/tests directory. No developer switch can keep a detected app inactive. Missing config/tools or nonexecuted/empty required suites fail. Templates below are inert, outside application inputs; adapt and validate in the first implementation PR. No application manifest or lockfile is fabricated now.
